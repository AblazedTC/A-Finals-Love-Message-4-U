# A Finals Love Message 4 U 💌

A cheerful, motivational web app built for [ColorStack](https://www.colorstack.org/) members to help CS students power through finals season.

## What it does

- **Inspirational Images** — Click the ✨ button to display a random cute/uplifting image with a smooth anime.js pop-in animation.
- **Cutesy Self-Love Letter** — Click the 💌 button to open an encouraging letter reminding you that you *can* make it through finals.
- **Floating Hearts Background** — Animated emoji hearts float across the screen to keep the vibes warm and cozy.

## Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styles | CSS3 + [system.css](https://github.com/sakofchit/system.css) (retro OS aesthetic) |
| Scripting | Vanilla JavaScript |
| Animation | [anime.js v3](https://animejs.com/) |

## Running locally

No build step required — just open `index.html` in your browser.

```bash
# Example with the VS Code Live Server extension, Python, or any static file server:
python -m http.server 8080
# then visit http://localhost:8080
```

## Project structure

```
.

├── index.html      # Main page
├── index.js        # App logic (image rotation, letter overlay, hearts animation)
└── styles.css      # Custom styles
```
